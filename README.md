**Math-A-Morphosis** (Project_Math) is an interactive, visual mathematics simulation platform designed to bring complex mathematical concepts and geometric algorithms to life. Through real-time canvas rendering, dynamic step-by-step visualizations, and adjustable parameters, this project helps users intuitively grasp mathematical theorems, linear transformations, and computational geometry algorithms.

---

## 🚀 Features & Modules

### 1. 🔷 Computational Geometry
* **Convex Hull Visualization:** Interactive point placement with real-time outer boundary generation using algorithms like **Jarvis March (Gift Wrapping)** and **Graham Scan**.
* **Chaos Game (Fractals):** Dynamic fractal generation (e.g., Sierpinski Triangle) using random iterative midpoint jumps.

### 2. 🔢 Number Theory & Calculus
* **Sieve of Eratosthenes:** Step-by-step visual elimination of composite numbers to isolate prime numbers within a range.
* **Riemann Sum Integration:** Visual approximation of definite integrals under curves using Left, Right, and Midpoint rectangle summations.

### 3. 🌊 Signal Processing & Transforms
* **Fourier Series & Epicycles:** Decomposition of periodic paths/waves into connected rotating epicycles using the Discrete Fourier Transform (DFT).
* **2D Matrix Transformations:** Interactive linear algebra grid illustrating $2 \times 2$ matrix scaling, rotation, shearing, reflection, and basis vector ($\hat{i}, \hat{j}$) shifts.

### 4. 📊 Statistics & Coordinate Systems
* **Least Squares Linear Regression:** Plot data points dynamically and observe the real-time best-fit line $y = mx + c$ alongside residual squared error boxes.
* **Interactive Graphing Calculator:** Expression parsing and continuous curve plotting.
* **Unit Circle & Trigonometry:** Side-by-side visualization linking unit circle angle rotation with live Sine/Cosine wave plots.
* **Vector Operations:** Graphical vector addition, subtraction, and dot product visualizers using head-to-tail mechanics.
